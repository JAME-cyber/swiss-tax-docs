# swiss-tax-docs MVP — Plan d'implémentation
> **Exécution:** TDD direct (MVP compact, contexte porté du prototype validé — pas de dispatch subagents).

**Goal:** librairie Python installable qui parse les décisions de taxation VD (PP) avec validators déterministes.
**Architecture:** voir `docs/specs/2026-09-29-mvp-design.md` (maquette approuvée).
**Stack:** Python ≥3.10, pdfplumber/pypdfium2 optionnels (extras), pytest, MIT.

## Tasks (TDD, commit par task)
1. **Scaffold** — pyproject (nom swiss-tax-docs v0.1.0, extras `[pdf]`, script CLI), LICENSE MIT, .gitignore, git init+commit.
2. **models.py** — TDD: `_montant("17'502","95")→17502.95`, `_montant("95'000.00")→95000.0`, dataclasses Ligne/DecisionTaxation, `.get()`, `.to_dict()`. Port direct du prototype validé.
3. **parsers/vd.py** — TDD: `detect()` (≥2 marqueurs; lettre normale → False), `parse_vd(text)` sur fixture synthétique: 5 checks verts + champs clés présents; fixture jurisprudence: notation fr.95 + libellé ICC agrégé; prose rejetée.
4. **validators.py** — TDD: falsification solde (+100.-) sur les 2 fixtures → warning; fixtures propres → zéro warning. (Plafonds VD: ICC ≤ 30% revenu, fortune ≤ 10‰.)
5. **extract.py** — lazy imports, `texte_pdf()` natif|ocr; test marqué integration (pas de PDF fixturé en v0.1).
6. **cli.py** — TDD: `python -m swiss_tax_docs.cli parse fixtures/... --json` → JSON avec champs+validations; exit 1 si document non reconnu.
7. **README + wrap** — badge-less, ton honnête FR: quoi/pas quoi, usage, limite 1 canton, ajout canton = 1 fichier, disclaimer fixtures synthétiques; run pytest complet; commit final.
